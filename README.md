# Weather Data Analysis

Python/Jupyter project for exploring and visualizing weather data.

## Category

Python, Data Analysis, Weather Analytics

## What This Project Shows

- Loading a weather dataset from CSV
- Inspecting data quality and summary statistics
- Exploring weather-related patterns
- Building simple visualizations for analysis
- Practicing a clean data analysis workflow in Jupyter Notebook

## Files

| File | Purpose |
| --- | --- |
| `weatherData.csv` | Dataset used for analysis |
| `WeatherDataAnalysis.ipynb` | Main analysis notebook |

## Tech Stack

`Python` `Jupyter Notebook` `Pandas` `NumPy` `Matplotlib` `Seaborn`

## How To Run

```bash
git clone https://github.com/Priyanka571705/weather-data-analysis.git
cd weather-data-analysis
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook WeatherDataAnalysis.ipynb
```

Or install from the included requirements file:

```bash
pip install -r requirements.txt
jupyter notebook WeatherDataAnalysis.ipynb
```
